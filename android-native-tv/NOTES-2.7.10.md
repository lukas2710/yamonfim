# TV 2.7.10 — séries vues

- Un épisode quitté pendant son générique, ou passé à la suite depuis le générique, est coché « vu », même sous 95 %.
- Une série dont le dernier épisode est terminé passe en « ✓ Vu », même s'il manque d'anciennes coches.

Validation : compilation Android, tests Java et signature par `build-apk.ps1`, depuis le code commité. Pas de test sur téléviseur.
